怎么用How it works

  1. 选一张图，页面用浏览器的解码器读出像素。 Choose an image; the page decodes its pixels with the browser's own decoder.
  2. 选输出格式、质量、最长边或目标体积，然后点「压缩」。 Pick an output format, quality, longest edge or target size, then press Compress.
  3. 预览结果并下载；文件只在本页生成。 Preview the result and download it; the file is produced in this tab.

如实说明的限制What it does not do

  • 一次只处理一张图；批量、更多格式与 ZIP 打包在扩展里。 One image at a time; batches, more formats and ZIP packaging live in the extension.
  • JPEG / WebP 的目标体积是尽力而为：先降质量，再缩尺寸；达不到时结果会显示实际大小。 A target size for JPEG / WebP is best-effort: lower quality first, then smaller dimensions; if it is still too big, the result shows the actual size.
  • PNG 没有质量参数，只能靠最长边控制大小，因此不提供目标体积。 PNG has no quality knob, so only its longest edge controls the size; there is no target-size field for PNG.
  • JPEG 会把透明区域铺成白色；WebP 与 PNG 保留透明通道。 JPEG flattens transparent areas to white; WebP and PNG keep the alpha channel.
  • GIF 与动态 WebP 只取第一帧；需要动画请保留原文件。 GIF and animated WebP keep only the first frame; keep the original if you need the animation.
  • 单文件上限 50 MB；超大像素图会被拒绝；画布最长边上限 4096 px，超出会先缩小。 One file up to 50 MB; an image with too many pixels is refused; the canvas is capped at 4096 px on its longest edge, and a larger image is scaled first.

常见问题Questions

图片会上传吗？Is the image uploaded?

不会。页面没有后端，也不会为图片发起网络请求；图片被读进当前标签页的内存，压缩与下载都在本页完成。 No. The page has no backend and never sends your image anywhere; the image is read into this tab's memory, and both compression and download happen here.

为什么 PNG 没有目标体积？Why is there no target size for PNG?

浏览器的 PNG 编码器不提供质量参数，所以这个工具只能通过最长边控制 PNG 大小；要追指定 KB，请选 JPEG 或 WebP。 The browser's PNG encoder exposes no quality setting, so this tool controls PNG size through its longest edge; choose JPEG or WebP when a target KB matters.

目标体积没达到怎么办？What if the target size is not reached?

目标是尽力而为：JPEG / WebP 会先降质量，再缩尺寸；如果仍然偏大，结果会显示实际大小。继续降低最长边通常能再小一截。 It is best-effort: JPEG / WebP lower quality first, then dimensions; if it is still over, the result shows the actual size. A smaller longest edge usually gets you closer.

会保留动画吗？Does it keep animation?

不会。GIF 与动态 WebP 只取第一帧，和扩展里的行为一致；需要动画请保留原文件。 No. GIF and animated WebP keep only the first frame, the same behaviour as the extension; keep the original file if you need the animation.

能一次压多张吗？Can I compress several images at once?

这个页面一次只处理一张。批量转换、预设与 ZIP 打包在 Chrome 扩展里，文件同样不上传。 This page handles one image at a time. Batches, presets and ZIP packaging live in the Chrome extension, and those files stay local too.
